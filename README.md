# Katalog UMKM Sekar Jagad Solo

Website katalog produk UMKM berbasis PHP yang dibuat untuk memenuhi tugas Hands-on Pertemuan 7 Pemrograman Web.

## Cara Menjalankan

1. Simpan folder katalog-umkm di dalam folder www Laragon.
2. Jalankan aplikasi Laragon.
3. Klik Start All untuk menjalankan Apache.
4. Buka browser.
5. Masukkan alamat http://localhost/p07/katalog-umkm/.

## Fitur

- Menampilkan daftar produk menggunakan foreach.
- Menampilkan status stok menggunakan match(true).
- Menyaring produk berdasarkan kategori.
- Menghitung jumlah produk dan nilai persediaan.
- Menampilkan harga dalam format Rupiah.
- Mengamankan teks menggunakan htmlspecialchars.
- Menampilkan label promo Gratis Ongkir.

## Struktur File

- data.php: menyimpan data toko dan produk.
- functions.php: menyimpan fungsi pengolahan data.
- index.php: mengatur alur dan tampilan website.
- style.css: mengatur desain halaman katalog.
